# WhatsApp Unban Pro: Death Legion Edition

The ultimate tool for WhatsApp account recovery, designed with the Death Legion aesthetic.

## 🚀 Pro Features

### 1. ⚡ Rapid Fire Mode
Send 50+ unique emails in sequence with a single click flow.
- The tool opens default mail client windows one by one.
- Requires enabling **Pop-ups** in your browser.

### 2. 🌍 Multi-Language Support
Generate professional appeals in over 50 languages including **Arabic, Sinhala, Hindi, Spanish, Indonesian, Russian**, and more. 
- Integrated translation logic for greetings and appeal reasons.

### 3. 🎯 Smart Ban Reason Engine
Select from verified unban methods:
- **Too Many OTP Guesses**: Specific appeal for "Guessing" errors.
- **Guest / New Number**: For numbers banned immediately after registration.
- **Scam / Video Call Reports**: Defense against false reports.
- **Business Policy**: Specialized appeals for WA Business.

### 4. 🎭 Gmail Alias Generator
Generate thousands of email variations (`username+support1@gmail.com`) to send appeals from "unique" addresses that route to your inbox.

### 5. 📝 Web Form Helper
Quickly fill the official [WhatsApp Contact Form](https://www.whatsapp.com/contact).
- Generates the perfect appeal text.
- One-click copy/paste buttons.

### 6. ⭐ Feedback Generator
Send 10+ unique positive/constructive feedback emails to `support@whatsapp.com` to improve your account standing and "karma" with their AI systems.

### 7. ☁️ Cloud Integration (Supabase/Firebase)
- Enter your API keys in the Settings tab.
- Automatically saves generated appeals to your database.
- Fully client-side logic (no intermediary server).

## 🛠️ Installation
1. Extract the folder.
2. Open **`index.html`** in Chrome, Edge, or Firefox.
3. No installation required. Runs locally.

## 🛡️ Privacy
This tool runs 100% on your device. Your phone number and data are not sent to any external server unless you configure the Cloud Settings yourself.
